# Portfólio — Ramon Chuinca (Vue 3 + Tailwind + Vite)

```bash
npm install
npm run dev       # desenvolvimento
npm run build     # gera a pasta dist/
```

**Netlify:** build command `npm run build`, publish directory `dist`.
O arquivo `public/_redirects` já faz o fallback do Vue Router.

- Textos, projetos e redes: `src/data.js` e `src/components/`
- Capas dos projetos: coloque as imagens em `public/img/` e preencha `image` em `src/data.js`
- Página de obrigado: rota `/obrigado` (também responde em `/thanks.html`)
